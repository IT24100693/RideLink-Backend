# RideLink Microservices Backend

## 📌 Overview
RideLink Backend is a microservices-based architecture built using **Spring Boot** and **MongoDB Atlas** for managing ride-sharing services, user accounts, and driver management.

## 🚀 Microservices
- **Account Service (`account-service`)**: Handles user registration, authentication, and user profile management.
- **Driver and Vehicle Service (`Driver-and-vehicle-service`)**: Manages driver profiles, vehicle details, and verification status.

## 🛠️ Tech Stack
- **Java 17+**
- **Spring Boot**
- **Spring Data MongoDB**
- **MongoDB Atlas**
- **Maven**
- **Git / GitHub**
